# Planificaciones futuras

Planes escritos y **sin aprobar**: existen para no volver a pensarlos desde cero el día que se
decidan. Cuando se apruebe uno, se mueve a `planes/por_hacer/`.

---

## Lo que hay aquí

- **[PLAN_REGISTRO_AUDITORIA.md](PLAN_REGISTRO_AUDITORIA.md)** — que quede rastro de quién hizo
  qué en las operaciones que mueven dinero. La tabla y la pantalla ya existen; **solo se escribe
  en ellas desde tres sitios**, así que aprobar un retiro o suspender una tienda no deja huella.
  Es el más valioso de los dos.
- **[PLAN_HISTORIAL_STOCK.md](PLAN_HISTORIAL_STOCK.md)** — historial de movimientos de stock, y
  con él el aviso de stock bajo, lo único que quedó fuera del módulo de notificaciones.

Los otros dos planes que vivían aquí se cerraron el 13/09/2026: **notificaciones** se construyó
entero, y **resolución de devoluciones** lo dejó superado el subsistema 5.
